# BCP-Vis 创新点增强方案（2026-09-12，v2）

> 约束（用户明确）：**创新点一（BCP 先验通道 + 因果验证）与创新点二（高度专家 → 背景专家 串行级联）
> 的宏观框架不得改变**。所有改进只能是「强化/增补」，不得替换宏观结构。

---

## 0. 证据驱动的薄弱环节（全部来自实测）

| 观察 | 数据 | 含义 |
|---|---|---|
| tiny@70m 最差且非单调 | tiny IoU：@50m 0.692 / **@70m 0.619** / @90m 0.754 | 高度条件未被下游利用 |
| BCP 增益随高度衰减 | Δ_IoU(tiny)：@50m +0.108 → @70m +0.024 → @90m +0.007 | 先验在下游「固定」使用，未随高度重标定 |
| 背景抑制与 tiny 冲突 | E8: FP↓32.4% 但 tiny 0.711→0.687；E12 先验≈P_f² | 概率域相乘的 S² 压制低置信光晕 |
| UAP 失效 | E13 −0.003 IoU、tiny −0.010、50m tiny −0.140 | `1−P_b` 结构性退化（P_b≈1−P_f ⇒ U≈0） |
| 因果验证只有零/随机两种干预 | E1/E2 | 可再加「错位」干预，三角验证更强 |

**共同根源**：Final CNN **没有高度信息**，只能用固定方式解读「可信度随高度变化」的先验；
且先验融合发生在概率域（相乘 ⇒ S²）。
→ 改进主轴：① 高度信号下传到先验使用侧；② 融合搬到证据(log-odds)域；③ 因果验证加第三种干预。

## 1. 已实现并排队（全自动串行：E13b → E16 → E18 → E17 → E19）

### E16 — ACPC 高度条件化先验通道（强化 一×二 协同）
```
h̃ = (h − 70) / 40 ;  e_h = MLP(1→32→2) ;  P' = (1+γ(e_h))·P + β(e_h)
X = [R, G, B, P'] → ResNet18-UNet
```
- 末层零初始化 ⇒ **起始严格恒等于 E12**（冒烟实测 identity_at_init=True），增益皆净增量。
- 单调保序（1+γ>0 时），参数仅 **130**（0.0012%）。
- 直接针对「增益随高度衰减」与 tiny@70m 非单调。
- 框架：四通道 concat 不变；级联 PriorNet 不动。对照 E12 唯一变量 `alt_cond`。

### E13b — UAP 独立先验修正（修复创新点三）
```
U = |P_f_cascade − P_f_litehr| （两独立架构专家的分歧 = 真不确定性）
P* = (1 − α·U) · P_f_cascade
```
- 根因修复：cascade 的 bg head 被监督成 1−前景 ⇒ `U=|P_f−(1−P_b)|≈0` ⇒ 原公式失效。
- 独立先验=litehr(E5)，复用 ckpt 无需重训。

### E17 — logit 证据融合先验（治 S²，强化创新点二第2级）
```
logit(P*) = α·logit(P_f) + logit(1−P_b),   α=1.0
```
- **数学依据**：两独立专家证据的正确组合是 log-odds 域**加法**（朴素贝叶斯），
  而概率域相乘隐含「双重复核」，当两头部相关时退化为 P_f²，压掉小目标光晕。
- 数值对比（P_f=0.7, 1−P_b=0.4）：乘法 0.28 vs logit 0.609 —— 不再平方压制。
- 对照 E12：唯一差异 = 先验融合域（概率域乘法 → 证据域加法），先验源/网络/训练全同。

### E18 — 错位先验因果对照（强化创新点一的因果验证，零训练）
```
P_misalign = roll(P, H/2, W/2)   # 保留边缘分布与局部光晕，只破坏空间对齐
```
- 用 E12 ckpt 直接在错位先验上评测。**第三次干预**：零 / 随机 / 错位。
- 判定：若 E18 ≈ E0/E2 ⇒ 增益确实来自先验的「空间对齐语义」⇒ 因果链闭合更强。
- 成本≈0（eval-only），论文价值高。

### E19 — 先验一致性正则（强化创新点一）
```
L = L_seg + λ_pc · (1 − Dice(σ(z), P)),   λ_pc = 0.1
```
- 把先验与输出的因果对齐显式写进训练目标（先验不只是输入，还是训练信号）。
- 默认 `lambda_pc=0`，不影响任何旧实验复现。对照 E19 vs E12 唯一变量 = λ_pc。

## 2. 路线图（E20 已实现，E21-E23 待实现）

### E20 — 双先验通道解耦（化解"先验 vs 背景专家"冲突）✅ 已实现排队
不再硬编码单通道 `P = P_f ⊙ (1−P_b)`（当 `P_b≈1−P_f` 时退化为 `P_f²`，压掉 tiny 光晕），
而是把**前景先验 `P_f` 与背景专家 `P_b` 拆成两个独立通道**，交给 CNN 自学融合：
```
X = [R, G, B, P_f, P_b]        （in_channels 4 → 5）
```
CNN 的 conv1 可学到 `w₁·P_f + w₂·(1−P_b)`（甚至非线性），**不再被强制平方**——
该保 tiny 光晕时保、该压背景时压，冲突被网络表达力吸收。与 E12 唯一差异 = 通道数与是否硬融合。
> 公平性：5 通道是**新消融变体**，不计入核心 3ch-vs-4ch 对照。

### E21 — 连续高度条件 PriorNet（强化创新点二内部）
把第 1 级离散 3 专家 MoE 换成 Fourier 特征 + 超网络连续条件：
`e_h=[sin(2^k π h̃), cos(2^k π h̃)] ; (γ,β)=MLP(e_h) ; F'=(1+γ)F+β`，消除档位断层；仍是高度级→背景级串联。

### E22 — 测试时先验自适应（现代 TTA，强化创新点一）
推理时用先验自监督更新 BN 仿射参数：`min_φ Dice(σ(z),P) + λH(σ(z))`。零参数零标注。

### E23 — 集成先验蒸馏（强化创新点一）
用 cascade+litehr+V4 三先验的 log-odds 加权平均作为更强教师先验重训 Final CNN。

## 4. 判定标准
- E16 有效 ⇔ 总体 IoU ≥ E12 且 tiny@70m 回升、tiny@50m 不退化。
- E17 有效 ⇔ tiny IoU 高于 E12（S² 缓解）且 FP 不明显升高。
- E18 预期**下降**（因果对照）：跌得越接近 E0/E2，因果证据越强。
- E19 有效 ⇔ 总体/tiny 任一改善且无副作用。
- 所有实验与 E12 严格同口径，唯一变量可控。
